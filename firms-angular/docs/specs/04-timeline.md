# Spec 04 — Timeline e playback

## Objetivo
Footer com período, histograma, range drag e animação.

## Dependências
Spec 02.

## Acceptance criteria
- [x] Presets Today / 7d / 24d / 30d / 60d
- [x] Histograma diário VIIRS/MODIS
- [x] Drag de range e click em dia
- [x] Play / step / 0.5× 1× 2× filtrando focos

## Fora de escopo
Calendário popup completo de dois meses (botão presente; grade pode evoluir).
