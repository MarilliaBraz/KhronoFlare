## Como escrever o seu

**Pelo site do GitHub (mais fácil):**

1. Abra o seu arquivo na tabela acima.
2. Clique no lápis (✏️ *Edit this file*) no canto superior direito.
3. Escreva embaixo de cada pergunta. Pode apagar as perguntas que não quiser responder.
4. Clique em **Commit changes...**, escreva uma frase curta (ex.: `docs: meus comentários`) e confirme.

**Pelo terminal:** edite o arquivo, depois `git add`, `git commit` e `git push`.

Regras simples:

- Edite **só o seu arquivo**. Assim ninguém sobrescreve o texto de ninguém.
- Escreva do seu jeito: tópicos, parágrafos ou os dois.
- Pode voltar e completar quantas vezes quiser.
- Seu commit faz você aparecer como *Contributor* do repositório.
